# Snapchat Offline Memories
---

This Node.js App serves as an offline memories library for Snapchat. Because of a recent update, you now have to buy Snapchat Premium to save your memories for more than 12 months. I don't want to buy Snapchat Premium. So I made this app.

# How to run (You'll need node.js installed)
---
1. 'npm install'
2. 'node server.js'

# Import files
---
- Use the import button *OR*
- Move one or more folders with your memories inside into the 'memories' folder
    - memories
        - my_memories
            - picture_1.jpg
            - video_1.mp4
